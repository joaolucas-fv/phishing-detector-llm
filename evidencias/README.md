# 📸 Evidências: Phishing Detector com LLM

## 📌 Apresentação

Esta pasta reúne evidências visuais dos experimentos realizados durante o desenvolvimento do projeto Phishing Detector.

As capturas de tela têm como objetivo demonstrar as análises feitas pelo Modelo de Linguagem, os resultados obtidos e as diferenças observadas entre as versões 1.0 e 1.1 do prompt.

## 🗂️ Organização das evidências

As imagens serão organizadas de acordo com o número dos testes e com as respectivas versões do prompt.

### 🔄 Comparação entre versões

| Teste | Tema |
|---|---|
| **Teste 02** | Interpretação de domínios e links |
| **Teste 08** | Precisão conceitual relacionada à LGPD |
| **Teste 09** | Divergência na classificação de risco |
| **Teste 03** | Diferenciação entre mensagens suspeitas e comunicações aparentemente legítimas |

## 🎓 Finalidade

As evidências complementam os registros e as avaliações disponíveis neste repositório e permitem visualizar exemplos das respostas produzidas pelo LLM durante os experimentos.

> [!NOTE]
> As capturas representam resultados de testes educacionais e não comprovam a eficácia do modelo na detecção de ameaças reais.
